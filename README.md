---

## 🌊 About

**Wave-Cafe** is a static front-end website template designed for cafes, coffee shops, or restaurant landing pages.  
It features a clean UI, responsive layout, and a video background to create an engaging user experience.

---

## ✨ Features

- 🎥 Full-screen video background  
- 📱 Fully responsive design  
- 🎨 Clean & modern UI  
- ⚡ Lightweight and fast  
- 🧩 Easy customization  

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
